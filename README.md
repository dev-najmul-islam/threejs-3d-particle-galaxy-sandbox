# 🌌 3D GPU Particle Galaxy & Black Hole Physics Sandbox (Three.js / WebGL)

An interactive **3D Cosmic Particle & Black Hole Physics Sandbox** built with **Three.js (WebGL 2.0)**, Tailwind CSS, and ES6 JavaScript — rendering thousands of glowing spiral galaxy particles with real-time orbital gravity, customizable spiral arms, and 360° camera controls at 60 FPS.

## ✨ Key Features
- **High-Density 3D Particle Engine:** Smoothly animates thousands of glowing star particles in spiral arms around a central black hole core.
- **Live Physics & Color Controls:** Adjust galaxy spin velocity, core gravity pull, and nebula color themes in real time.
- **Zero-Build Setup:** Clean HTML5, Tailwind CSS, and ES6 JavaScript — runs directly in any modern browser.
- **Desktop & Mobile Touch Ready:** Full 360° mouse drag, scroll zoom, and touch gesture support.
